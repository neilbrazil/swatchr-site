What Swatchr does

  • Live camera picker

    Drag the crosshair over anything the camera can see. The color reads out as you move, so you can hunt for the exact shade instead of taking a photo and hoping.

  • Pick from your photo library

    Open any saved image and tap a point in it. Useful for screenshots, product photos and reference shots taken months ago.

  • Four formats, always visible

    Hex, RGB, HSL and CMYK sit on screen together. Tap the one you need and it goes to the clipboard. No format switcher, no menu.

  • A name for every color

    Each pick is matched to the nearest of the 140-odd CSS color keywords, so you get Cadetblue or Rosybrown rather than only a six-digit code.

  • Harmony suggestions

    Alongside each color you get its opposite on the wheel and the two neighbors 30 degrees either side, all with their own hex codes.

  • Saved palette, widget and export

    The one-time unlock adds an unlimited saved palette, a Home Screen widget showing your latest color, and export cards you can share.

How it works

  1. 1

    Open the camera or a photo

    Two buttons on the first screen. Nothing to set up, no account to make.

  2. 2

    Move the crosshair

    Drag it over the color you want. Tap once to freeze the reading so a shaky hand doesn't lose it.

  3. 3

    Tap the code you need

    Hex for CSS, RGB for most design tools, HSL for tweaking, CMYK for anything heading to print.

Questions

How do I find the hex code of a color in a photo on my iPhone?

Open the photo in Swatchr, tap the point you want, and the hex code appears with the RGB, HSL and CMYK values underneath. Tap the hex row to copy it. iOS also has a hidden eyedropper in the Markup tool, though it only gives you one value at a time.

Learn more

Can I pick a color from my camera instead of a photo?

Yes. The camera view samples continuously as you drag the crosshair, so you can read the color of a wall, a fabric or a printed sample without photographing it first. Tap to freeze the reading once you have it.

Learn more

What is the difference between hex, RGB, HSL and CMYK?

Hex and RGB describe the same screen color in different notation. HSL splits it into hue, saturation and lightness, which makes manual adjustment much easier. CMYK describes ink coverage for print.

Learn more

Does Swatchr give CMYK values for print work?

It does, on the same readout as everything else. Treat the numbers as a starting point rather than a press-ready spec, because the conversion has no printer profile behind it.

Learn more

How do I find a color that goes with the one I picked?

Swatchr shows three suggestions under each color: the hue rotated 180 degrees, and the two hues 30 degrees either side. Saturation and lightness stay put so the suggestions look related rather than random.

Learn more

Can I save colors into a palette?

The saved palette is part of the one-time unlock. Once it is on, there is no limit on how many colors you keep, and they stay on the device rather than syncing to a server.

Learn more

What if I do not know what a color is called?

Every pick is matched to its nearest CSS color keyword, so a murky yellow-green comes back as Darkolivegreen. It is an approximate match by distance in RGB, which is enough to describe a color to somebody else.

Learn more

Is there a Home Screen widget?

Yes, included in the unlock. The small widget shows your most recent saved color as a filled swatch with its name and code, which is handy when you are working to a palette all week.

Learn more

Does Swatchr work without an internet connection?

Everything runs on the device. There is no account, no sync and no server, so the camera and photo picking both work in airplane mode.

The download is free and the camera picking, photo picking and all four format codes are free with no usage limit. Saving to a palette, the widget and export cards are behind a single one-time purchase, not a subscription.
